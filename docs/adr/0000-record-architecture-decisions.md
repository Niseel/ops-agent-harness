# 0000. Record architecture decisions

Status: Accepted · Date: 2026-09-26

## Context

We need a lightweight, versioned record of significant technical decisions.

## Decision

Use Architecture Decision Records: one Markdown file per decision in `docs/adr/`, in the format described in [README.md](README.md).

## Consequences

Decisions are reviewable in pull requests and become part of the audit trail.
